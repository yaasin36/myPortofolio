Website Sejuk

Website Sejuk is a modern café website dedicated to selling refreshing milkshakes and smoothies. It features a fresh, vibrant, and interactive user interface designed to attract customers and provide a seamless menu browsing experience.

Built with essential web technologies including HTML, CSS, and JavaScript, and supported by a MySQL database, the platform offers dynamic product displays and a responsive layout that perfectly adapts to mobile and desktop screens.
